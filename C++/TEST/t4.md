数据项 (Data Item):
学号 (Student ID): 学生的唯一标识符。
姓名 (Name): 学生的姓名。
性别 (Gender): 学生的性别 (男/女)。
班级号 (Class ID): 班级的唯一标识符。
班级名称 (Class Name): 班级的名称 (如 计算机科学与技术2023级1班)。
系别 (Department): 学生所属的系。
课程号 (Course ID): 课程的唯一标识符。
课程名 (Course Name): 课程的名称。
学时 (Credit Hours): 课程的总学时。
学分 (Credits): 课程的学分。
学期 (Semester): 课程开设的学期 (如 第一学期, 第二学期)。
工号 (Teacher ID): 教师的唯一标识符。
职称 (Title): 教师的职称 (如 讲师, 副教授)。
职务 (Position): 教师的职务 (如 班主任, 系主任)。
平时成绩 (平时 Score): 学生在课程中的平时表现分数 (0-100)。
考试成绩 (Exam Score): 学生在课程中的考试分数 (0-100)。
总评分 (Total Score): 学生在课程中的最终总评分 (0-100)，计算公式为 平时成绩 × 0.3 + 考试成绩 × 0.7。
年份 (Year): 学生所在的年级 (如 2023级)。
日期 (Date): 成绩单生成的日期。
及格分数线 (Passing Score Line): 定义及格的标准 (通常为60分)。
数据结构 (Data Structure):
新生信息 (New Student Info): { 学号, 姓名, 性别, 班级号, 系别 }
班级信息 (Class Info): { 班级号, 班级名称, 年份, 系别 }
课程信息 (Course Info): { 课程号, 课程名, 学时, 学分, 学期 }
教师信息 (Teacher Info): { 工号, 姓名, 性别, 职称, 职务 }
班级课程信息 (Class Course Info): { 班级号, 课程号, 学期, 任课教师工号 }
学生课程成绩 (Student Course Grade): { 学号, 课程号, 平时成绩, 考试成绩, 总评分 }
数据流 (Data Flow):
新生信息录入 (New Student Info Entry): 从外部输入新生信息到系统。
课程信息录入 (Course Info Entry): 从外部输入班级、课程、教师信息到系统。
学生名册 (Student Roster): 从系统输出学生信息给教师。
成绩录入 (Grade Entry): 从教师输入学生的平时成绩和考试成绩到系统。
总评分计算 (Total Score Calculation): 系统根据平时成绩和考试成绩计算总评分。
成绩单输出 (Grade Report Output): 系统输出不同格式的成绩单。
数据存储 (Data Store):
学生信息库 (Student Info Store): 存储所有学生的基本信息。
班级课程信息库 (Class Course Info Store): 存储班级、课程、学期、任课教师之间的关系。
教师信息库 (Teacher Info Store): 存储教师的基本信息。
成绩信息库 (Grade Info Store): 存储学生在各门课程中的成绩详情。
过程 (Process):
输入新生信息 (Input New Student Info): 接收新生入学时的信息并存储。
输入课程信息 (Input Course Info): 接收每学期的课程安排和任课教师信息并存储。
分发学生名册 (Distribute Student Roster): 根据班级和课程从系统获取学生名单并发送给任课教师。
输入成绩 (Input Grades): 接收任课教师输入的学生平时成绩和考试成绩。
计算总评分 (Calculate Total Score): 根据公式计算学生的总评分。
生成成绩单 (Generate Grade Reports): 根据需求生成全班单科、全班汇总或个人成绩单。
统计分析 (Statistical Analysis): 对成绩进行统计分析 (及格率, 平均分等)。
